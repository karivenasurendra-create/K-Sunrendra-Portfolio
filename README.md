# Portfolio — K Naga Surendra

This is a premium portfolio scaffold (dark, glassmorphism) built with HTML/CSS/JS.

How to use
- Replace `images/*` with your photos and project images.
- Add your real `resume.pdf` in the project root.
- Open `index.html` in a browser to preview.

Included
- `index.html`
- `css/style.css`, `css/responsive.css`
- `js/script.js` (Typed.js, Particles, AOS init)
- `images/` placeholder SVGs

CDNs used: Google Fonts, Font Awesome, AOS, Typed.js, Particles.js
